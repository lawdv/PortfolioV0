## Cómo actualizar PortfolioV0
1. Descomprime este paquete.
2. Abre https://github.com/lawdv/PortfolioV0
3. Usa **Add file → Upload files** para subir `index.html`, `styles.css`, `script.js` y `simulador-dron.html` a la raíz.
4. Confirma los cambios con **Commit changes**.
5. **No elimines la carpeta `img/` que ya existe** en tu repositorio. La nueva página reutiliza esas imágenes para las tarjetas de aplicaciones y el juego de Unity.

La página del simulador debería quedar en:
https://lawdv.github.io/PortfolioV0/simulador-dron.html

El formulario conserva el endpoint de Formspree ya configurado en tu portafolio anterior.
